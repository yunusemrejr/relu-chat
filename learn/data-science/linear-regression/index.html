Linear Regression

Linear regression predicts a continuous target as a weighted sum of features, fit by ordinary least squares (OLS).

Definition

y^=wTx+b\hat{y} = w^Tx + by^​=wTx+b where www minimizes ∑i(yi−wTxi−b)2\sum_i (y_i - w^Tx_i - b)^2∑i​(yi​−wTxi​−b)2, the residual sum of squares (RSS).

Closed-form solution: w=(XTX)−1XTyw = (X^TX)^{-1}X^Tyw=(XTX)−1XTy (when XTXX^TXXTX is invertible).

Intuition

Each coefficient wjw_jwj​ tells you the expected change in yyy for a one-unit increase in xjx_jxj​, holding all else constant.

OLS is the best linear unbiased estimator (BLUE) under Gauss-Markov assumptions: linearity, exogeneity, homoscedasticity, no perfect multicollinearity.

Worked example

Predicting weight from height: y^=−100+0.9×height(cm)\hat{y} = -100 + 0.9 \times \text{height(cm)}y^​=−100+0.9×height(cm), so each extra cm adds about 0.9 kg.

In practice

Baseline regression model; interpretable coefficients make it the go-to for explanatory modeling.

Check residual plots for non-linearity, heteroscedasticity, and outliers — violations indicate model misspecification.
