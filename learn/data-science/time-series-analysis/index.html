Time Series Analysis

Time series analysis handles data ordered chronologically, where temporal dependencies matter.

Ask the Data science assistant →1 min read · Updated September 9, 2026
On this page
  1. Definition
  2. Intuition
  3. Worked example
  4. The math

Definition

Key feature: autocorrelation — yty_tyt​ is correlated with yt−1y_{t-1}yt−1​, yt−2y_{t-2}yt−2​, etc. (unlike i.i.d. data).

Trends (long-term direction) and seasonality (cyclical patterns) are core components: Yt=Tt+St+RtY_t = T_t + S_t + R_tYt​=Tt​+St​+Rt​ (additive) or multiplicative.

Intuition

Standard regression assumes independent observations — time series violates this, so standard errors and p-values are wrong if you ignore it.

The autocorrelation function (ACF) plots correlation vs. lag; the partial autocorrelation (PACF) controls for intermediate lags.

Worked example

Monthly retail sales: trend (growing over years) + seasonality (holiday spike in December) + remainder.

Stock prices are nearly random walk (autocorrelation near zero) — difficult to predict.

The math

ARIMA(p,d,q)(p,d,q)(p,d,q): autoregressive (AR) order ppp, differencing order ddd, moving-average order qqq. ∇dyt\nabla^d y_t∇dyt​ is stationary and modeled as ARMA(p,q)(p,q)(p,q).

A time series is stationary if mean, variance, and autocorrelation are constant over time — differencing achieves this.

In practice

Used for demand forecasting, inventory planning, financial prediction, and anomaly detection in monitoring systems.

Modern methods (Prophet, Temporal Fusion Transformers) handle multiple seasonality and external regressors (holidays, promotions).
