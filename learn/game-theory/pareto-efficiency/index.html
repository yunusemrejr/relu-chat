Pareto Efficiency

An allocation is Pareto efficient if no player can be made strictly better off without making someone else worse off.

Definition

Allocation aaa Pareto dominates bbb if ui(a)≥ui(b)u_i(a)\ge u_i(b)ui​(a)≥ui​(b) for all iii and strict for some iii. An allocation is Pareto efficient if no alternative Pareto-dominates it.

The Pareto frontier is the set of all Pareto-efficient allocations.

Intuition

It is the minimal standard for collective rationality: if everyone prefers xxx to yyy, then yyy should never be chosen.

Pareto efficiency is necessary but not sufficient for social optimality — it says nothing about distribution.

Worked example

In the Prisoner's Dilemma, (C,C)(C,C)(C,C) Pareto-dominates (D,D)(D,D)(D,D), yet (D,D)(D,D)(D,D) is the unique Nash equilibrium.

Any competitive equilibrium in a market is Pareto efficient (First Welfare Theorem).

The math

Mapping from strategy profiles to the payoff space Rn\mathbb{R}^nRn, the Pareto frontier consists of maximal points under the componentwise partial order.

Scalarization: maximizing ∑iλiui\sum_i \lambda_i u_i∑i​λi​ui​ for positive weights λ\lambdaλ traces the frontier for convex payoff sets.

Where it is used

Used as a welfare benchmark in every branch of economics — trade, regulation, taxation, and mechanism design.

Pareto improvements are the gold standard for policy evaluation.
