Congestion Games

Games where each player's payoff depends on the load each facility carries.

Definition

Players choose subsets of facilities EEE; payoff ui(s)=−∑e∈sice(fe(s))u_i(s)=-\sum_{e\in s_i}c_e(f_e(s))ui​(s)=−∑e∈si​​ce​(fe​(s)) where fe(s)f_e(s)fe​(s) is the number of players using eee.

Nonatomic (continuous flow) and atomic (discrete) variants yield Wardrop and Nash equilibria respectively.

Intuition

Every facility's cost depends only on its total usage, not on who uses it.

Always a potential game, so pure equilibria always exist.

Worked example

Selfish routing on Pigou's network shows the Price of Anarchy =4/3=4/3=4/3 for linear latencies (Roughgarden-Tardos).

Job scheduling on identical machines is a congestion game.

The math

Rosenthal (1973): every congestion game has the exact potential Φ(s)=∑e∑k=1fe(s)ce(k)\Phi(s)=\sum_e\sum_{k=1}^{f_e(s)}c_e(k)Φ(s)=∑e​∑k=1fe​(s)​ce​(k), hence a pure Nash equilibrium.

Beckmann-McGuire-Winsten variational formulation gives Wardrop equilibrium as a convex program.

Where it is used

Internet routing (BGP), transportation planning, load balancing in data centers, and cloud resource allocation.

Core in algorithmic game theory.
