Principal-Agent Problem

A contracting problem where an agent's action is unobservable to the principal.

Intuition

Effort must be induced through output-contingent compensation that balances risk-sharing and incentives.

Information asymmetry requires trading off insurance for motivation.

Worked example

CEO compensation via stock options aligns manager and shareholder incentives but imposes risk.

Sharecropping (Stiglitz) splits output to induce effort when labor is unobservable.

Where it is used

Executive pay, procurement contracts, insurance, and regulation.

Cornerstone of contract theory.
